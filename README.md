# ASICs Mining Dashboard

A polished, responsive single-page mining dashboard inspired by the supplied reference image.

## Features

- Dark neon dashboard UI with responsive desktop, tablet, and mobile layouts
- Arabic-first interface with one-click English localization
- Interactive navigation, notifications, demo logout, market search/filtering, plan selection, and action feedback
- No build step or external runtime dependencies: open `index.html` directly or serve the folder with any static web server

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
Responsive mining dashboard inspired by the provided reference image, with Arabic and English localization.
